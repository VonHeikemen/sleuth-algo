# sleuth

This plugin automatically adjusts `'shiftwidth'`, `'tabstop'` and `'expandtab'`
heuristically based on the current file.

## Usage

Use the command `:Sleuth` to detect and change the indentation of the current file.

```vim
:Sleuth
```
